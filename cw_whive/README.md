# cw_whive

Whive cryptocurrency wallet integration for Cake Wallet.

## About Whive

Whive is a Bitcoin-based cryptocurrency with the following network parameters:
- Default Port: 8372
- Address Prefix (PUBKEY): 73 (addresses start with 'W')
- Address Prefix (SCRIPT): 10
- Bech32 HRP: "wv"

## Getting Started

This package provides Whive wallet functionality built on top of cw_bitcoin's Electrum infrastructure.
